# Payment-method marks

These marks appear on the borrower's "Choose how to pay" tiles to show which payment methods the portal accepts. They are trademarks of their owners. This is a demo mockup, and the marks are used only to identify each payment method. They are drawn through `<img>` data URLs, so the SVG files can't run scripts or load anything.

| File | Mark | Source | Licence |
|---|---|---|---|
| `gcash.svg` | GCash | Wikimedia Commons, "File:GCash logo.svg" | Public domain |
| `maya.svg` | Maya | Wikimedia Commons, "File:Maya logo.svg"; author: Maya Bank, Inc. and PayMaya Philippines, Inc. | CC BY 4.0, https://creativecommons.org/licenses/by/4.0 |
| `qrph.svg` | QR Ph | Wikimedia Commons, "File:QR Ph Logo.svg" | CC0 |
| `visa.svg` | Visa | Wikimedia Commons, "File:Visa Inc. logo (2021–present).svg" | Public domain |
| `mastercard.svg` | Mastercard | Wikimedia Commons, "File:Mastercard 2019 logo.svg" (a `viewBox` was added so it scales) | Public domain |
| `maribank.png` | MariBank | Header logo on maribank.ph, cropped to the mark and resized to 608 × 140 | MariBank trademark, shown only to identify the payment method |

All files were downloaded on 2026-11-26. Before they were added, each SVG was checked for scripts, event handlers, `foreignObject`, external links and embedded images, and none were found.
